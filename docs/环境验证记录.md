## 下载来源与处理记录

- JDK：Azul 官方 CDN，SHA-256 与官方包元数据一致。
- Gradle：GitHub 重定向下载缓慢，改用华为云镜像；压缩包 SHA-256 与 Gradle 官方发布值一致。Wrapper 当前也使用该镜像和相同官方校验值。
- Android 工具：Google 官方源，SHA-1 与官方 SDK repository XML 一致。
- SDK Manager 许可流程完成，但包下载阶段长时间无进展。改用官方压缩包，经校验后安装；可通过安装脚本 `-DownloadSdkArchives` 复现。网络停滞的底层原因尚未确定，不归因于 App 代码。
- SDK 许可处理、工具安装和本机自检均已执行；`.tools/setup-direct.log` 和 `.tools/doctor.log` 保存过程输出。
- 首次 Gradle 构建中部分 Kotlin JAR 从 Maven Central 下载缓慢；对停滞文件使用镜像下载，并核对 Maven Central 官方 SHA-1 后写入本机内容寻址缓存。工程仓库配置保持 Google Maven / Maven Central / Gradle Plugin Portal，缓存不纳入版本控制。
