# 简记 1.1.0 更新说明

日期：2026-10-26。版本 1.1.0，versionCode 4；包名 `com.example.jianji`。沿用 1.0.0 正式签名，数据库仍为 schema v1，无需改表或清空账本。

## 消费类型管理

从「设置 → 消费类型管理」或记账表单的「管理类型」进入。离开表单管理类型后，返回时保留当前账单草稿。

- 添加：名称 1～12 个 Unicode 字符，选择 8 种标识颜色之一，最多保留 200 个类型（含停用类型）。
- 修改：自定义和内置类型均可改名、换色，稳定 ID 保持不变，历史明细和统计同步显示新名称与颜色。
- 删除：二次确认；未关联消费记录的类型物理删除，已关联记录的类型停用。停用后不能用于新账单，已有账单保留原类型并可继续编辑，历史筛选与统计仍包含它。
- 恢复：在「已停用」区域恢复使用；如果关联账单已全部删除，可以再次删除类型以彻底移除。
- 重名：先做 Unicode NFKC、首尾空白处理和大小写归一后校验；停用名称也保留，避免同名统计歧义。禁止控制字符、不可见格式字符和非法代理项。

实现：CategoryViewModel 管理草稿、提交中状态和错误；RoomExpenseRepository 使用与消费写入相同的锁及事务，检查分类引用后删除或停用，同时更新变更序号。事务失败整体回滚。编辑/删除传入原类型快照，发现类型已变化时提示重新确认；添加草稿保存固定 ID，重复保存不会创建两个相同类型。

## 统计图表

| 图表 | 展示内容与交互 |
|---|---|
| 环形图 | 各消费类型的金额占比；中心显示类型数量 |
| 饼图 | 相同分类统计的实心扇区图，与环形图共用统计快照 |
| 柱状图 | 按金额降序排列的类型支出，以 0 为基线；支持横向滚动与点击柱体进入明细 |
| 折线图 | 全部类型的时间趋势；点击曲线查看所选时间段金额，也可展开文字数据列表 |

图表选择保存在 DataStore，离开页面或重启后沿用。分类图表超过 8 类时展示前 7 类与「其余类型」，完整分类明细仍保留，合并项钻取包含其全部类型 ID。

趋势范围不超过 62 天时按日汇总；超过 62 天且涉及不超过 24 个自然月时按月汇总；更长范围按年汇总。首尾只包含选定范围内的日期，不额外纳入整月/整年的账单。缺少记录的时间段补 0，单日只展示一个点。横轴为时间，纵轴为元；轴上大金额缩写为万/亿，点击及文字列表展示精确金额。汇总保持整数分，绘图坐标才转浮点数。

实现：TrendCalculator 负责分桶、补零和边界裁剪；StatisticsViewModel 连接 Room 查询与图表偏好；Charts.kt 使用 Compose Canvas 绘制圆形图/折线，Compose 布局绘制柱图。没有增加联网或第三方图表服务。

## UI 改进与修复

- 统一松绿主色、柔和背景、圆角卡片、标题字重和间距，浅色/深色同步适配。
- 明细与统计使用统一渐变汇总卡，突出金额、笔数和日均，错误状态不显示为真实的零支出。
- 设置页加入醒目的类型管理入口；管理页区分使用中与停用类型，颜色选项有名称及选中状态。
- 类型标识按 Unicode 码点截取，避免 emoji 被截成半个字符。
- 设置页版本原来写死为 0.2.0，导致升级后仍显示旧版本；改为使用 BuildConfig.VERSION_NAME。
- 类型编辑弹窗在自动宽度测量下反复触发布局；改为明确的宽度约束和可滚动内容，完整交互测试验证通过。
- 管理列表原本的底部浮层会遮挡末尾操作按钮；添加入口移至顶部，操作提示单独占用布局空间。
- 补齐 Material 3 的容器与选中态配色，消除默认紫色；主题选项使用整行单选语义，扩大触摸区域。
