# 简记 1.1.1：分类占比标注

日期：2026-10-26。versionCode 5，沿用原正式签名和数据库 schema v1。

环形图与饼图现在直接标注消费类型及占比，例如「餐饮 26.1%」。标签分列图形两侧，通过同色引线连接对应扇区；环形图中心继续显示类型数量。百分比沿用金额聚合结果，保留一位小数，四舍五入后合计可能不等于 100%。合并的「其余类型」显示合并占比。

实现位于 `ui/CircularChart.kt`：先测量标签文字的实际高度，再按扇区中点分配左右位置，同侧标签按垂直方向排序和错位排列。内容较多或字号较大时增加图表高度，避免小扇区、长名称挤在一起；名称保留完整文本，并可由无障碍服务读取。两种图表共用同一套标注逻辑。

验证包括已有记账/类型管理/图表切换流程，以及 360dp 窄屏、1.3 倍字体、8 个长名称类型且 7 个小扇区聚集的布局测试；自动检查所有标签位于图表范围内、互不重叠。截图由实际 Compose 页面和测试账本生成，已检查普通浅色与密集深色场景。
